Official DentalAI widget integration. Adds your AI receptionist to your WordPress site in 1-click.

== Description ==

The DentalAI Chatbot plugin allows dental clinics to seamlessly integrate their AI receptionist into their WordPress website. 
Without touching any code, you can easily load the floating chat widget to handle patient inquiries, book appointments, and provide 24/7 support.

= Features =
* Simple 1-click configuration
* Securely isolated iframe rendering ensures zero CSS conflicts with your theme
* Automatic mobile and desktop responsiveness
* No API keys required on your website—uses your secure public Clinic ID

== Installation ==

1. Upload the `dentalai-widget` folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Navigate to the new 'DentalAI' menu in your WordPress admin sidebar.
4. Paste your Public Clinic ID (found in your DentalAI Dashboard) and save.

== Frequently Asked Questions ==

= Where do I find my Clinic ID? =
Log into your DentalAI dashboard, navigate to "Website Integration", and copy the ID provided.

= Will this slow down my website? =
No. The widget script is loaded asynchronously with `defer`, meaning it will not block your page from rendering.
