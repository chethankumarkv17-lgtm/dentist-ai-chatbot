### Recommended Image Specs:
- **Aspect Ratio**: 4:5 (e.g. 800px × 1000px or 1200px × 1500px)
- **Format**: JPG, PNG, or WebP
- **Style**: High-quality monochrome / grayscale portrait or clean headshot against a neutral background.
- **Note**: If a photo file is omitted or missing, the website will automatically display an editorial placeholder avatar with initials.
